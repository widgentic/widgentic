The template tree's format control offers `count`, `join`, `truncate` and `pluralize` with their fields, committing a valid spec on every type switch; editing plural forms keeps the categories and locale the row does not show. A text bind row gains a Markdown toggle that hides `map` and `format` while it is on. A bind whose format reads a list (count, join, pluralize) completes the schema's array paths instead of marking them off-schema.

# Reference Links

Curated references that inform widgentic's direction. Grouped by area.

## MCP integration

- [Building MCP apps with Azure Functions MCP Extension](https://techcommunity.microsoft.com/blog/appsonazureblog/building-mcp-apps-with-azure-functions-mcp-extension/4496536)
  Microsoft overview of using the Azure Functions MCP extension to build MCP-enabled apps. Relevant as a reference host/runtime that could emit widgentic payloads from tool results.
- [MCP as easy as 1-2-3: Introducing the fluent API for MCP apps](https://devblogs.microsoft.com/azure-sdk/mcp-as-easy-as-1-2-3-introducing-the-fluent-api-for-mcp-apps/)
  Azure SDK fluent API for MCP. Relevant for ergonomic patterns when wrapping widgentic-emitting tools.

## UI runtime

- [Arrow JS](https://arrow-js.com/)
  Lightweight reactive UI library focused on simple DOM updates. Aligns with widgentic's renderer-agnostic, low-overhead direction for the rendering layer.

## Design systems

- [Awesome Design Systems](https://github.com/alexpate/awesome-design-systems/tree/master?search=1)
  Curated collection of design system resources. Useful when defining widget visual primitives (card, table, tree) without inventing a full theming system.
